# Phase 8 — UI Design Contract

> Visual and interaction contract for the agrune DevTools webapp. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

Phase 8 extends the existing `@agrune/devtools` Vite webapp — single-page, vanilla TypeScript, no framework. The existing panel (snapshot browser) ships. This phase adds: command log view, HITL pause/resume/skip controls, failure diagnostics, and session list with active-badge + focus action. Existing Catppuccin Mocha palette and SF Mono typography are preserved so new surfaces feel like the same tool.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (vanilla TS + Vite) |
| Preset | not applicable |
| Component library | none — hand-rolled DOM primitives in `panel.ts` / new `logs.ts` etc. |
| Icon library | Unicode glyphs only (▸ ▾ ⏸ ▶ ● ⚠ ✕ ⭐ ↻). Matches existing tool. No icon package added. |
| Font | `'SF Mono', Monaco, 'Cascadia Code', monospace` — inherit `body` rule in `panel.css` |

**Stack rule:** do NOT introduce React/Vue/any framework, Tailwind, CSS-in-JS, shadcn, or icon packages. Phase 8 is additive to the existing webapp.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gap, inline padding, reason-dot margins |
| sm | 8px | Compact element spacing, toolbar button gap |
| md | 16px | Card padding, log row horizontal padding |
| lg | 24px | Section padding, empty-state offset |

Exceptions:
- Toolbar and log rows already use 6px vertical / 10px horizontal in the existing file; new code uses 4 / 8 / 16 (multiples of 4). Existing 6/10 values are NOT refactored in Phase 8 (scope lock).
- Detail pane width stays at 280px (existing).

Additional semantic colors (kept minimal, already in panel.css):
- `#a6e3a1` (green) — success state, connected status, paused-toggle accent, HITL resume button color
- `#fab387` (peach) — offscreen / hidden reason
- `#f9e2af` (yellow) — sensitive / warn (HITL `paused` state badge)
- `#89dceb` (sky) — source/file reference text
- `#89b4fa` (blue) — action-kind badges

Accent (`#cba6f7` mauve) reserved for:

## Copywriting Contract

All English, match existing devtools tone (terse, developer-facing, lowercase allowed).

| Element | Copy |
|---------|------|
| Primary CTA — session focus | `Focus session` |
| Primary CTA — HITL resume | `Resume` |
| Primary CTA — HITL step | `Step` |
| Secondary — HITL pause | `Pause next tool` |
| Destructive — HITL skip | `Skip current call` |
| Empty state heading — logs | `No commands yet` |
| Empty state body — logs | `Call an MCP tool to see events stream here.` |
| Empty state heading — sessions | `No sessions` |
| Empty state body — sessions | `Launch agrune in a tab, then use agrune_focus to activate one.` |
| Empty state heading — failures | `No failures` |
| Empty state body — failures | `Latest tool call succeeded.` |
| Error state — WebSocket disconnected | `Disconnected. Retrying…` |
| Error state — command failure card | `{tool_name} failed: {error_code}. {one-line hint}.` |
| Active session badge | `ACTIVE` |
| Paused badge | `PAUSED` |
| Destructive confirmation — Skip current call | `Skip current call?` + note `The tool will return a 'skipped' error to the caller.` (native `window.confirm` modal, no custom dialog) |

Voice rules:
- Verbs in imperative (`Focus session`, not `Click to focus`).
- Never use "Submit" / "OK" — name the outcome.
- Session list items show `{title || url} (tab {id})` — existing pattern preserved.

## Interaction Contracts (Phase-Specific)

Not part of the checker template, but downstream consumers need these. Keep frozen.

### Layout

Three vertical tabs in the existing toolbar row (new tab-bar just below toolbar):

1. **Snapshot** (existing panel — unchanged)
2. **Logs** (new — command log stream)
3. **Sessions** (new — session list + focus control)

Failure diagnostics surface inside Logs (inline-expandable card on failed rows). No separate "Failures" tab.

HITL controls are persistent in the toolbar (visible from all tabs) — they act on the active session regardless of current tab.

### WebSocket events (additive)

New inbound event types (server → client). Existing `sessions_update` and `snapshot_update` unchanged.

- `command_event` — `{ data: { id, ts, sessionId, tool, phase: 'start'|'end'|'error', durationMs?, error? } }`
- `hitl_state` — `{ data: { paused: boolean, pausedAt?: number, pendingTool?: string } }`

New outbound event types (client → server). Existing `subscribe` and `highlight` unchanged.

- `hitl` — `{ action: 'pause'|'resume'|'skip'|'step' }`
- `focus_session` — `{ sessionId }`

### HITL state machine

- `paused=false, pendingTool=null` → toolbar shows "Pause next tool" button only.
- `paused=true, pendingTool=null` → yellow `PAUSED` badge + "Resume" button.
- `paused=true, pendingTool='agrune_click'` → yellow `PAUSED` badge + tool name + "Resume" / "Step" / "Skip current call" buttons.

Transitions fire the outbound `hitl` event. Server is the source of truth; UI renders whatever `hitl_state` last reported.

### Command log row

```
[HH:MM:SS] session#3 agrune_click   42ms  OK
[HH:MM:SS] session#3 agrune_fill    —     FAIL ⚠
```

Click-to-expand on FAIL rows reveals a `.failure-detail` card with:
- error code (mono, red)
- tool args preview (truncated 240 chars)
- current manifest hash + version
- target selector (if any)

Client buffer: last 500 events, FIFO. No persistence (session-volatile — per CONTEXT.md deferred list).

### Session list row

```
● {title} (tab {id})  [ACTIVE]  <Focus>
```

- Mauve dot + `ACTIVE` badge on the active session.
- `Focus` button hidden on the already-active row.
- Clicking `Focus` sends `focus_session`; server calls `agrune_focus` path and broadcasts fresh `sessions_update`.
