# Phase 7 Plan 02: resolveTabId, Active Tracking on Execute, and focusSession in CdpDriver

## Objective
- **What:** `BrowserDriver` 인터페이스에 `focusSession`을 추가하고, `CdpDriver`의 `resolveTabId`·`execute`·`listSessions`를 active session 개념으로 통합한다. `agrune_focus` 툴이 드라이버 레벨에서 동작할 수 있도록 `Target.activateTarget`/`Page.bringToFront`를 best-effort로 호출한다.
- **Why:** SESS-02(resolve 우선순위)와 SESS-03(focus 툴의 런타임 구현)을 하나의 레이어(브라우저 드라이버)에 모아두면, Plan 03의 MCP 레이어는 orchestration(인수 검증, 응답 포맷)만 담당하게 된다.
- **Output:** 개편된 `cdp-driver.ts`·`driver.ts`·`core/index.ts` + 새 테스트. Plan 01의 `SessionManager` API에 의존.

    **4. `resolveTabId(tabId?: number)`(현재 286-292줄) 전체 본문을 교체한다.** 최종:
    ```ts
    resolveTabId(tabId?: number): number | null {
      if (typeof tabId === 'number') return tabId

      const activeId = this.sessions.getActiveSessionId()
      if (activeId !== null && this.sessions.getSession(activeId) !== null) {
        return activeId
      }

      const sessions = this.sessions.getSessions()
      const ready = sessions.find(session => session.snapshot !== null)
      return ready?.tabId ?? sessions[0]?.tabId ?? null
    }
    ```

    **5. 새 public 메서드 `focusSession`을 `resolveTabId` 바로 아래에 추가한다:**
    ```ts
    async focusSession(tabId: number): Promise<FocusResult> {
      const session = this.sessions.getSession(tabId)
      if (!session) {
        throw createCommandError(
          'TAB_NOT_FOUND',
          `No session exists for tabId ${tabId}.`,
          { tabId },
        )
      }

      const wasActive = this.sessions.getActiveSessionId() === tabId
      this.sessions.setActiveSession(tabId)

      let cdpFocusError: string | undefined
      const target = this.targetManager.getTarget(tabId)
      if (target) {
        try {
          await this.connection.send('Target.activateTarget', { targetId: target.targetId })
        } catch (error) {
          cdpFocusError = error instanceof Error ? error.message : String(error)
        }
        if (target.sessionId) {
          try {
            await this.connection.send('Page.bringToFront', {}, target.sessionId)
          } catch (error) {
            if (!cdpFocusError) {
              cdpFocusError = error instanceof Error ? error.message : String(error)
            }
          }
        }
      }

      return {
        tabId,
        wasActive,
        becameActive: true,
        ...(cdpFocusError ? { cdpFocusError } : {}),
      }
    }
    ```

    Note: `createCommandError`는 `@agrune/core` export이고 현재 파일 import 2줄에 이미 포함되어 있음(`import { createCommandError } from '@agrune/core'`). throw하는 에러는 CommandErrorShape 구조이므로 호출자가 잡아서 MCP 응답으로 포맷할 수 있다.

    **6. 기존 테스트 호환:** `CdpDriver`가 `BrowserDriver` 인터페이스를 `implements`하므로 `focusSession`이 필수로 요구된다. 위 4/5번 변경만으로 interface 충족. 다른 메서드는 건드리지 않는다.

- [ ] `execute`가 성공 시 `touchSession(tabId)`를 호출한다
- [ ] `focusSession`이 알 수 없는 tab에 대해 TAB_NOT_FOUND를 던지고, 알려진 tab에 대해 active를 바꾸고 best-effort CDP focus를 호출한다
- [ ] `listSessions`의 결과에 `active` 플래그가 붙는다
- [ ] Interface `BrowserDriver`가 `focusSession`을 요구한다
- [ ] 기존 빌드/타입/단위 테스트 전부 green
