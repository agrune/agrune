# Phase 5 Plan 02: Rewrite handleFill to Use CDP Input Domain

## Objective
- **What:** `handleFill`이 Plan 01의 `eventSequences` 프리미티브를 사용하도록 재작성하고, contenteditable·masked input·clear 옵션을 지원하도록 확장한다. 기존 `setElementValue`는 `strategy === 'dom-setter'` (숨은 fallback) 경로로만 남긴다.
- **Why:** 현재 DOM setter + `input`/`change` 이벤트 방식은 controlled input·contenteditable·masked input에서 실패한다. CDP 경로로 통일해야 `agrune_fill`이 결정적으로 동작한다.
- **Output:** 확장된 `handleFill` + strategy 선택 로직 + contenteditable 지원.

       ```ts
       function detectMaskedInput(element: HTMLElement): boolean {
         if (element.getAttribute('data-agrune-masked') === 'true') return true
         if (!(element instanceof HTMLInputElement)) return false
         const type = element.type
         if (type === 'tel') return true
         const inputMode = element.getAttribute('inputmode')
         const pattern = element.getAttribute('pattern')
         if ((inputMode === 'tel' || inputMode === 'numeric') && pattern) return true
         // Heuristic: common masking libraries set these attrs/classes
         if (element.className && /\\b(cleave|masked|imask)\\b/i.test(element.className)) return true
         return false
       }
       ```

       ```ts
         element.focus({ preventScroll: true })
         // Verify focus landed — headless can drop focus.
         if (document.activeElement !== element && !isContentEditable) {
           // Retry once.
           element.focus()
         }
         if (isContentEditable) {
           const selection = window.getSelection()
           const range = document.createRange()
           range.selectNodeContents(element)
           selection?.removeAllRanges()
           selection?.addRange(range)
           if (!clear) {
             selection?.collapseToEnd()
           }
         } else if (clear) {
           await deps.eventSequences.selectAllAndDelete()
         }

         if (strategy === 'dom-setter') {
           // Legacy fallback.
           if (element instanceof HTMLInputElement || element instanceof HTMLTextAreaElement) {
             setElementValue(element, input.value)
           }
           return
         }

         if (strategy === 'keystroke') {
           await deps.eventSequences.typeText(input.value)
           return
         }

         // strategy === 'insert'
         await deps.eventSequences.insertText(input.value)
       }
       ```
