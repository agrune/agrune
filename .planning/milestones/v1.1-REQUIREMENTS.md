# Requirements: agrune v1.1 Browser Completion

**Defined:** 2026-04-18
**Core Value:** AI 에이전트가 의미를 이해할 수 있는 제어 표면(`data-agrune-*` 어노테이션)을 통해 웹 앱을 로컬·결정적·검증 가능하게 자동화한다.

## v1 Requirements

milestone v1.1의 목표는 CDP-only 피봇 이후 브라우저 본체의 입력 신뢰성·복구력·다중 탭 UX·devtools 웹앱·품질 인프라·문서를 닫는 것이다. 각 요구사항은 로드맵 phase(5번부터 시작)에 매핑된다.

### Input Reliability

현재 `fill`이 DOM setter + `input`/`change` 이벤트 경로에만 의존하여 controlled input, contenteditable, masking 시나리오에서 실패한다 (`runtime/command-handlers.ts:289-306`). CDP `Input.insertText`/`Input.dispatchKeyEvent` 기반으로 통일한다.

- [ ] **INPUT-01**: `agrune_fill`이 CDP `Input` 도메인 경로로 controlled input(React/Vue/Angular)에 값 설정을 반영한다
- [ ] **INPUT-02**: `agrune_fill`이 `contenteditable` 요소에 텍스트를 결정적으로 입력한다
- [ ] **INPUT-03**: `agrune_fill`이 masked input(tel, card number 등)에서 포매팅을 깨뜨리지 않고 값을 설정한다
- [ ] **INPUT-04**: `agrune_fill`이 기존 값을 지운 뒤 새 값을 입력하는 동작을 옵션으로 지원한다

### Stability & Recovery

현재 CDP 연결 손실·Chrome crash는 수동 재실행을 요구한다. self-healing 루프를 도입해 자동 복구하고 실패 시 명확한 에러로 종결한다.

- [ ] **HEAL-01**: CDP 연결 손실이 감지되면 자동으로 재연결을 시도하고 성공/실패가 MCP 응답에 반영된다
- [ ] **HEAL-02**: Chrome 프로세스 crash 시 launcher가 자동으로 재시작하고 세션을 재연결한다
- [ ] **HEAL-03**: 재연결 후 페이지 런타임 주입(`CdpRuntimeInjector`)과 manifest 상태가 자동으로 resync 된다
- [ ] **HEAL-04**: 복구 실패 시 MCP 응답에 에러 코드·원인·사용자 액션 가이드가 반환된다

### Multi-Tab / Session UX

현재 `resolveTabId()`가 "첫 세션" 기준이라 사용자가 여러 탭을 열었을 때 엉뚱한 탭을 조작한다. active session 개념과 `agrune_focus` 도구로 의도를 명확화한다.

- [ ] **SESS-01**: `SessionManager`가 active session 개념을 갖고 최근 상호작용 탭을 추적한다
- [ ] **SESS-02**: `tabId` 미지정 호출 시 active session 우선 규칙으로 탭을 resolve 한다
- [ ] **SESS-03**: `agrune_focus` 도구가 특정 세션으로 active 전환을 수행한다 (`docs/superpowers/specs/2026-03-*-focus-*.md` 스펙 연결)
- [ ] **SESS-04**: 사용자가 devtools 웹앱에서 active session을 확인·전환할 수 있다

### DevTools Webapp

현재 devtools 웹앱은 snapshot viewer + pause/resume만 제공한다. 명령 로그·HITL 제어·실패 진단으로 자동화 세션을 관찰·개입할 수 있게 한다.

- [ ] **DEVT-01**: devtools 웹앱에서 실행된 MCP 명령 로그를 시간순·필터 가능한 뷰로 확인할 수 있다
- [ ] **DEVT-02**: devtools 웹앱에서 HITL(human-in-the-loop) step 단위 일시정지·재개·스킵을 제어할 수 있다
- [ ] **DEVT-03**: 명령 실패 시 devtools 웹앱에 원인·대상 노드·어노테이션 상태가 진단 표시된다
- [ ] **DEVT-04**: devtools 웹앱이 여러 세션/탭을 목록으로 보여주고 선택/전환 UX를 제공한다 (SESS-04 UI 표면)

### Quality Infrastructure

현재 vitest 단위 테스트만 존재하고 실제 브라우저를 띄우는 E2E가 없다. 또한 annotation 오류가 런타임까지 가서야 드러난다.

- [ ] **QUAL-01**: Overlay/modal 포함 시나리오를 실제 브라우저로 실행하는 E2E 테스트 프레임이 레포에 존재하고 CI에서 실행된다
- [ ] **QUAL-02**: `data-agrune-*` 어노테이션을 빌드 타임에 검증하는 build-linter가 레포에 존재한다 (`docs/superpowers/specs/2026-03-29-build-linter-design.md` 스펙 실행)
- [ ] **QUAL-03**: build-linter가 중복/누락/오타 annotation을 보고하고 CI에서 실패 조건으로 작동한다

### Docs & Distribution

CDP-only 피봇 이후 문서 다수가 dual-entry 시절을 반영한 상태다. 외부 공개 표면(조직 프로필)까지 포함해 메시지를 맞춘다.

- [ ] **DOCS-01**: `agrune/README.md`·`AGENTS.md`·`docs/notes/`·`docs/improvement-notes.md`에서 extension mode 잔재 표현을 제거하고 CDP-only 현실을 반영한다
- [ ] **DOCS-02**: `.github/profile/README.md` (github.com/agrune 조직 프로필)를 CDP-only·`@agrune/mcp` 메시지로 재작성한다
- [ ] **DOCS-03**: `agrune` CLI 플래그(`--headless`·`--attach`·`--port`·`--no-devtools`·기본 포트 47654)가 `--help`와 README에 문서화된다
- [ ] **DOCS-04**: automation profile import/복제 UX(문서 + CLI 동작)가 정리되고 README에서 발견 가능하다

## v2 Requirements

v1.2+ 로 연기된 항목. v1.1 로드맵에는 포함되지 않으며, 별도 milestone으로 다룬다.

### Desktop Expansion

- **V2-DESK-01**: macOS AX-first hybrid 프로토타입 (v1.0 GO 권고)
- **V2-DESK-02**: 지원 앱 compatibility matrix 실측
- **V2-DESK-03**: Manual profile UX 설계 (데스크톱 맥락)
- **V2-DESK-04**: Vision fallback confidence UX

### Additional Automation Surfaces

- **V2-AUTO-01**: `agrune_capture` (`docs/superpowers/specs/` 스펙 있음)
- **V2-AUTO-02**: `agrune_draw` (스펙 있음)
- **V2-AUTO-03**: `agrune_system-interaction` (스펙 있음)
- **V2-AUTO-04**: QA 자동 시트 3종 `agrune_qa_*` (스펙 있음)
- **V2-AUTO-05**: 범용 캔버스 지원 전략

## Out of Scope

영구 제외 또는 v1.1 한정 제외.

| Feature | Reason |
|---------|--------|
| Extension mode 복원 | 2026-04-15 피봇으로 완전 제거, 재도입 계획 없음 |
| Native messaging host | Extension 제거와 함께 폐기, CDP stdio로 충분 |
| Backend daemon | Extension 제거와 함께 폐기, MCP stdio 단일 진입 |
| 사이드패널 채팅 UI / 에이전트 허브 | Extension 제거와 함께 폐기된 방향 |
| Universal direct annotation | v1.0 synthesis에서 NO-GO |
| Vision-first positioning | v1.0 synthesis에서 NO-GO |
| 클라우드 기반 기본 OCR/비전 파이프라인 | 로컬 우선/개인정보 원칙과 충돌 |
| Windows/Linux 지원 | macOS 우선 유지, 추후 별도 milestone |
| macOS/AX 데스크톱 확장 (v1.1 한정) | 브라우저 본체 완성 우선, v1.2+ 로 연기 (2026-04-18) |
