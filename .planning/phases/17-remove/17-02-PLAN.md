<objective>
**E2E bootstrap shim을 manifest-only 경로로 재작성하고 `legacy-annotated.html` fixture의 의미를 반전한다.**

Wave 1(17-01)이 runtime src에서 legacy 경로를 제거한 뒤, E2E 레이어는 세 가지 부채를 정리해야 한다:

1. **Inline bootstrap script rewrite** — `packages/e2e/tests/user-flow/helpers.ts` (L320-379)와 `packages/e2e/fixtures/idle-boot.html` (L13-54)의 inline bootstrap이 `buildManifest(scanAnnotations(...), scanGroups(...))` 경로를 참조. 이 경로는 17-01에서 src에 없어졌으므로 bootstrap이 throw하거나 silently 아무 target도 생성하지 못한다. Manifest-only path로 재작성.
2. **Fixture semantic reversal** — `legacy-annotated.html`은 v1.1까지 "runtime이 legacy annotation을 scan해서 부팅한다"를 긍정 증명하던 fixture. Phase 17 이후에는 "runtime이 legacy annotation을 **무시한다**"를 긍정 증명하는 fixture로 의미가 반전된다. 파일명은 allow-list 대상이므로 유지.
3. **Spec assertion reversal** — `bootstrap-idle.spec.ts` L28-35의 `legacy-annotated.html: runtime boots active via inline scan` assertion을 `source=idle` positive로 뒤집는다.

이 plan은 17-01에서 발생한 known regression (bootstrap-idle `legacy-annotated` fail)을 해소해 E2E suite을 다시 green으로 돌린다.

Purpose: 17-01의 runtime 삭제가 E2E 레벨에서도 유지되게 하고, fixture를 "legacy 무시"를 증명하는 live regression harness로 승격.
Output: 수정된 helpers.ts / idle-boot.html / legacy-annotated.html / bootstrap-idle.spec.ts / annotation-scan.spec.ts + `pnpm test:e2e` green.
