# Phase 6 Plan 01: Error Codes & Lifecycle Hooks

## Objective
- **What:** 자동 복구 로직이 쓸 "연결 손실"·"Chrome crash" 감지 지점을 `CdpConnection`과 `ChromeLauncher`에 hook 형태로 추가하고, 복구 실패를 표현할 에러 코드 3종을 `@agrune/core`에 등록한다.
- **Why:** Plan 02의 `RecoverySupervisor`가 공통 감지 지점 없이는 동작할 수 없다. hook/코드만 먼저 확정해 Plan 02가 "배선 + 재연결 시나리오" 조립에만 집중하도록 한다.
- **Output:** 감지 hook 2개, 에러 코드 3개, launcher의 spawn 주입 seam. 단위 테스트로 hook이 호출됨을 검증.

  <action>
    `packages/browser/src/cdp-connection.ts`에 disconnect hook을 추가한다. 기존 public API(`connect`, `disconnect`, `isConnected`, `send`, `on`, `off`)는 시그니처를 그대로 둔다. 변경 내용:

    1. 클래스 필드 추가 (기존 필드 바로 아래, `private listeners = ...` 다음 줄에):
    ```ts
    private disconnectListeners = new Set<(reason: Error) => void>()
    private disconnectSuppressed = false
    ```

    2. 새 public 메서드 두 개 (예: `off(...)` 바로 아래):
    ```ts
    onDisconnect(callback: (reason: Error) => void): () => void {
      this.disconnectListeners.add(callback)
      return () => {
        this.disconnectListeners.delete(callback)
      }
    }
    ```

    3. `disconnect()` 내부에서 "의도적 disconnect"는 hook을 건드리지 않도록 한다. `disconnect()` 함수 첫 줄(`if (!this.socket) return`) 바로 아래에 다음 한 줄을 추가:
    ```ts
    this.disconnectSuppressed = true
    ```
    그리고 `disconnect()`의 맨 마지막 줄 `this.handleDisconnect()` **뒤**에 다음 한 줄 추가:
    ```ts
    this.disconnectSuppressed = false
    ```

    4. `handleDisconnect()` 본체(현 162-168 lines)를 교체 — pending 거절은 그대로 두고 끝에 socket 정리와 listener fan-out을 더한다:
    ```ts
    private handleDisconnect(reason?: Error): void {
      const pending = [...this.pending.values()]
      this.pending.clear()
      const err = reason ?? new Error('CDP connection disconnected.')
      for (const entry of pending) {
        entry.reject(err)
      }
      if (this.socket) {
        this.socket = null
      }
      if (this.disconnectSuppressed) return
      const listeners = [...this.disconnectListeners]
      for (const listener of listeners) {
        try {
          listener(err)
        } catch {
          // listeners must not propagate
        }
      }
    }
    ```

    5. 기존 `connect()` 내부에서 close/error 리스너 호출을 `this.handleDisconnect()` → `this.handleDisconnect(new Error('CDP socket closed.'))` / `this.handleDisconnect(error instanceof Error ? error : new Error(String(error)))`로 바꾼다. 구체적으로:
    - `socket.on('close', () => this.handleDisconnect())` →
      `socket.on('close', () => this.handleDisconnect(new Error('CDP socket closed.')))`
    - `socket.on('error', () => this.handleDisconnect())` →
      `socket.on('error', (error) => this.handleDisconnect(error instanceof Error ? error : new Error(String(error))))`

    다른 메서드(`send`, `on`, `off`, `handleMessage`)는 건드리지 않는다.
  </action>
